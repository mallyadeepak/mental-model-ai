# Systems & Architecture — A Field Guide

A single-file, interactive drill-down mental model covering system design, architecture principles, and code-level judgment for principal engineers — built to teach yourself or a team.

## Contents

Eight domains, click-to-expand as deep as the topic warrants:

- Scalability & Performance
- Distributed Systems Foundations
- Data Architecture
- Architecture Styles & Principles
- Reliability & Operability
- Security Architecture
- Code-Level Architecture
- Principal Engineer Judgment

Each node opens a detail drawer with a plain-English description, a real-world analogy, a "why it matters at the principal level" note, and — where relevant — a common pitfall. A search box jumps straight to any concept by name.

## Running it

No build step. Open `index.html` directly in a browser, or serve it statically:

```bash
npx serve apps/systems-architecture-guide
```

It's a standalone HTML/CSS/JS file — no dependency on the rest of this monorepo's build pipeline.
